# First-use confidence

## Design

- Keep the compact graphite/cyan command deck and expose the existing task-group starters as a single keyboard-accessible rail only while Find is empty and unfiltered.
- When native reasoning is disabled, direct the operator to the real Optional local reasoning section in Settings without exposing a machine path. Browser guidance remains browser-only.
- Put desktop readiness before the model editor. Derive every status from the already-loaded runtime and capability reply; unknown or malformed native replies remain “Not confirmed.”
- Treat copy and insertion capability as availability, never proof that an operation succeeded. Keep Enter as copy, Shift+Enter as insertion, and provide no execution path.

## Acceptance

- A starter fills the query, applies its matching task group, returns a relevant catalog result, disappears after selection, and never copies, inserts, or reasons.
- Disabled native reasoning shows Configure reasoning, which opens Settings and focuses Optional local reasoning. No home/config path appears in the disabled native message; `configPath` remains in the status API for diagnostics.
- Settings distinguishes local search, copy, and insertion for native and browser runtimes, includes Wayland/wl-copy and Hyprland/wtype requirements, and makes no success claim.
- Codex disclosure exists only when Codex is the reported provider. Browser mode never calls native configuration or model commands.
- Native verification replaces query text with Home, Shift+End, BackSpace; copy uses Return and insertion uses Shift+Return without an extra terminal submission.
